# Surveying-upstream-water-level-automatic-flood-detection-and-warning-system-with-dam-control.-
Implemented IOT based project: Arduino Uno, WIFI Module (ESP8266), GSM Module (SIM900A), Ultrasonic Sensor, DHT11 Sensor, Power Supply (7-12V), Miscellaneous (Wires, resistors, etc.
1. Continuously survey water levels and store it on cloud.
2. Automatic Flood detection. 
3. Automatic Flood warnings sent to villagers via SMS (Wireless).
4. Automatic Dam door control until flood stops.
